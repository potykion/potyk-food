# Оформление рецепта

## Workflow

1. Переименовать файл: **английский kebab-case** (как остальные рецепты), например `chicken-w-potato.md`, `beshbarmak.md`.
2. Перенести в нужную категорию под `docs/recipes/` (основные блюда → `04-main-course/`).
3. Обновить ссылку в `docs/index.md` в соответствующем разделе.
4. Привести содержимое к шаблону ниже.
5. Удалить исходный клиппинг/черновик, если он остался вне `docs/recipes/`.

## Шаблон файла

```markdown
# Название блюда на русском

- https://example.com/recipe

![Название](https://example.com/title-photo.jpg)

## Ингредиенты:

<!-- вариант A: таблица -->
| Продукты |        |
| -------- | ------ |
| Продукт  | кол-во |

<!-- или вариант B: список -->
- Продукт количество

## Приготовление:

- Шаг 1.
- Шаг 2.
```

## Правила

- **Без frontmatter / пропсов** (`title`, `source`, `author`, `tags`, `description` и т.п.) — убрать всё.
- **Ссылку на рецепт** оставить только в тексте: буллет со URL сразу под заголовком.
- **Убрать все лишние ссылки**: шаринг (VK, OK, Telegram и т.д.), категории сайта, блог автора, «добавить в записную книжку», смежные рецепты, cookie/политика и прочий мусор клиппинга. Оставить только URL самого рецепта.
- **Фото**: убрать все пошаговые и декоративные изображения; **оставить только титульное** фото блюда (под ссылкой на рецепт).
- Заголовки именно **`## Ингредиенты:`** и **`## Приготовление:`**.
- **Ингредиенты** можно оформить и как **таблицу**, и как **буллет-лист** — оба варианта допустимы; если в исходнике уже таблица, сохранять/починить таблицу (в т.ч. секции «для теста», «для подачи»).
- **Приготовление** — **только буллет-лист** (каждый шаг отдельным `-`), не нумерованные абзацы и не сплошной текст.
- Убрать маркетинговое описание, порции/тайминги из клиппинга и лишние метаданные, если пользователь не просит их сохранить.
- Имя файла и путь — как у соседних рецептов в той же папке (`chicken-w-…`, `…-w-veggies` и т.д.).
