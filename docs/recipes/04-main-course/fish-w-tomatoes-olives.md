# Рыба, запеченная с помидорами и оливками по-средиземноморски

- https://www.russianfood.com/recipes/recipe.php?rid=179180

![Рыба, запеченная с помидорами и оливками по-средиземноморски](https://www.russianfood.com/dycontent/images_upl/885/big_884352.jpg)

## Ингредиенты:

| Продукты (на 2 порции)           |                |
| -------------------------------- | -------------- |
| Филе белой рыбы (у нас хек)      | 500 г          |
| Помидоры черри                   | 300 г          |
| Оливки зелёные без косточек      | 100 г          |
| Тимьян сушеный                   | 1 ч. ложка     |
| Розмарин сушеный                 | 1 ч. ложка     |
| Орегано сушеный                  | 1 ч. ложка     |
| Петрушка свежая                  | 20 г           |
| Чеснок                           | 4 зубчика      |
| Базилик свежий                   | 10 г           |
| Лимон                            | 1 шт.          |
| Соус чили (по желанию)           | 30 мл          |
| Масло оливковое                  | 50 мл          |
| Соль                             | 1/2 ч. ложки   |
| Перец чёрный молотый             | 1/4 ч. ложки   |

## Приготовление:

- Подготавливаем продукты. Включаем духовку для разогрева до 200 °C.
- С лимона снимаем цедру и выжимаем сок. Соединяем лимонный сок, цедру, соль, перец, соус чили (по желанию), сушеные травы, оливковое масло и пропущенный через пресс чеснок.
- Петрушку и базилик мелко рубим.
- Добавляем зелень в маринад и тщательно перемешиваем.
- В жаропрочную форму выкладываем рыбное филе, заливаем пряным маринадом и аккуратно перемешиваем. Раскладываем рыбу в один слой. (При желании можно филе разрезать на кусочки.)
- Помидоры черри разрезаем пополам. Слегка присаливаем и перчим из общего количества.
- Выкладываем помидоры и оливки между кусочками рыбы.
- Отправляем в разогретую до 200 °C духовку на 25 минут до готовности рыбы.
- Готовую рыбу сразу подаём к столу, при желании полив образовавшимся при запекании ароматным соусом.
